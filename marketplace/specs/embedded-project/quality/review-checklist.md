# Review Checklist

每次 agent 完成实现或修改后，必须按以下清单自检。

## 架构检查

- [ ] 新增文件是否放在正确目录？
- [ ] 是否违反单向依赖？
- [ ] 是否把业务逻辑写入 `drivers/`？
- [ ] 是否把硬件操作写入 `app/`？
- [ ] 是否让 `protocols/` 直接操作硬件？

## 编码检查

- [ ] public API 是否清晰？
- [ ] 是否有未受控全局变量？
- [ ] 是否存在 magic number？
- [ ] 是否存在无边界 buffer 写入？
- [ ] 是否存在不合理动态内存？
- [ ] 是否存在被忽略/屏蔽的编译警告或静态检查告警？
- [ ] 跨设备/跨芯片协议字段是否明确处理了字节序？

## 运行时检查

- [ ] 是否存在阻塞等待？
- [ ] 是否存在 ISR 复杂逻辑？
- [ ] 是否存在未保护共享状态？
- [ ] 是否正确处理 DMA buffer 所有权？
- [ ] 是否存在关中断/临界区时间过长的风险？
- [ ] tick 或时间戳比较是否处理了回绕？
- [ ] 看门狗喂狗是否反映真实系统健康状态，而非无条件喂狗？
- [ ] 是否评估了关键 task 的栈使用和溢出风险？

## 质量检查

- [ ] 是否有错误处理路径？
- [ ] 是否有日志或诊断策略？
- [ ] 是否说明测试或验证方式？
- [ ] 是否存在 `NEED_CONFIRMATION`？

## 输出检查

- [ ] 是否列出修改文件？
- [ ] 是否说明所属层级？
- [ ] 是否说明 public API 变化？
- [ ] 是否说明未完成项或人工确认项？
